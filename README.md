# mod-quick-complete —— 快速补全

Mindustry 聊天输入自动补全 Mod（**纯客户端**，仅 Windows 桌面客户端，不含服务端/安卓逻辑）。

- 目标版本：Mindustry **v159.7**（官方端）与 MindustryX **B485**（基于 v159.7），一份 jar 通用。
- **隐藏 mod（`hidden: true`）**：不进入客户端 mod 列表，避免多人连接时因「多余 mod」被服务器拒绝。
- 原理：反射拿到聊天输入框 `ChatFragment.chatfield`，在其上叠加补全候选与按键拦截。

## 功能

### 三种补全模式

| 模式 | 进入方式 | 候选内容 | 退出 |
|---|---|---|---|
| 标准 | 默认（输入非空且有前缀匹配） | 自己发过的完整消息 | — |
| 后缀 | 光标在文本**末尾**时，再按一下 `→` | 消息末尾词语/标点（出现 ≥3 次） | `←` 回到标准 |
| 前缀 | 光标在文本**最前**时，再按一下 `←` | 游戏内全部颜色标签（静态） | `→` 回到标准 |

- 模式切换键 `←`/`→` 仅在「光标已在边界 + 一次全新按下」时触发；**长按 `→` 把光标拉到末尾的过程不触发**（松开后再单独按一下才算）。实现用边沿触发，天然忽略长按重复。
- 三种模式下：`↑`/`↓` 移动高亮，`Tab` 补全当前高亮。

### 标准模式

- 词库记录**自己发送**的所有消息（普通聊天、`/` 命令、`/t`/`/a` 私聊）。
- **前置指令剔除**：`/t`、`/a`、`/achat`、`/r` 等「指令 + 空格 + 文本」时，只记录/补全其后的有效文本，指令前缀不计入词库计数（如 `/t hello` 只记 `hello`）。
- 首次发送 = 临时（次数 1），再次发送 → 永久（次数 ≥2），计数**跨会话累计**。
- 前缀匹配（大小写敏感）、按出现次数排序。
- **忽略颜色前缀**：匹配时自动去掉 `[颜色]` 标签，如输入「你好」仍能匹配保存过的 `[pink]你好啊`（显示为完整 `[pink]你好啊`）。这类匹配**不做 ghost 预览**，只进候选列表。
- **部分匹配**：输入匹配到词库句子里 ≥N 个连续字符（N 在设置里可调，默认 3）时，即使前面词不匹配也列入候选；`Tab` 默认**覆盖全部文字**为完整句子，设置里可改为「仅粘贴不替换」。
- 恰好 1 条「字面前缀」匹配：输入框内显示低透明度 ghost 预览；其余情况：显示候选列表。
- **输入框为空时不显示候选列表。**
- 排序/焦点：次数升序展示，但**最高频放倒数第二行（默认焦点）、次高频放最后一行**，往上依次第三、四、五高……即：
  ```
  5th高(1次)
  4th高(3次)
  3rd高(5次)
  1st高(10次)  ← 默认焦点（Tab 补全它）
  2nd高(8次)   ← 最下方
  ```

### 后缀模式

- 从自己发的每条消息抽取「末尾片段」分别计数：结尾标点串（如 `！` `。` `...`）+ 最后一个词（空格分隔）或 CJK 末尾 1~4 字 n-gram。总次数 **≥3** 才进入候选。
- 切换到后缀模式**立即显示全部后缀候选**（后缀是「追加到末尾的新内容」，不受当前文本末尾字符影响，如文本结尾是 `1` 仍会列出 `喵`）。
- 进入后再输入的字符作为筛选前缀；`Tab` 把选中后缀追加到进入时的文本末尾（替换筛选输入），随后回到标准模式。

### 前缀模式（颜色标签）

- 静态表（**不学习**）：38 个命名色 + 18 个深浅预设（浅红/深红/浅黄/深黄/浅蓝/深蓝…，十六进制），每个配中文名与色系。
- 切换到前缀模式**立即显示全部颜色**。
- 输入即**搜索**（支持部分文字）：输入「红」→ 红色系（红色/深红/浅红/粉色…）；输入「浅黄」→ 浅黄；输入 `re` → `[red]`。
- 预览：光标后无消息内容时显示「预览文字」（染成该色），有内容时显示该内容（染成该色）。
- **16 进制**：输入 `#RRGGBB` / `#RRGGBBAA` 时列表顶部显示该色，可补全插入 `[#RRGGBB]`。
- `Tab`：把**搜索文字替换**为 `[颜色]`（如「红色」→ `[red]`），保留光标后的原消息，随后回到标准模式。整条染色，不加闭合 `[]`。

## 词库存储

- 位置：`<游戏数据目录>/quick-complete/wordlib.dat`（`Core.settings.getDataDirectory()`，Windows 下通常为 `%APPDATA%/Mindustry/`）。
- 格式：文本文件，`[MESSAGES]` 与 `[SUFFIXES]` 两段，每条 `次数 \t 最近使用 \t base64(文本)`。
- 全局一份（所有服务器共用），发送后即时落盘。

## 构建

要求：JDK 17+（已用 JDK 25 验证 `--release 17` 编译通过）、`libs/mindustry-v159.7-server-release.jar`。

```powershell
cd mod-quick-complete
powershell -File build.ps1      # 或直接双击 build.bat
```

产物：`build/quick-complete.jar`（含 `mod.hjson` + class 文件）。

## 安装

1. 打开 Mindustry（v159.7 官方端或 MindustryX B485）→「模组」→「导入模组」→ 选择 `quick-complete.jar`。
2. 启用「快速补全」。
3. 打开聊天（默认 `Enter`/`T`）即可使用。

## 按键速查

| 按键 | 行为 |
|---|---|
| 输入非空 | 标准补全（前缀匹配消息词库） |
| `Tab` | 补全当前高亮候选（单条时为 ghost 补全） |
| `Shift+Tab` | 保存当前项（次数不足 2 直接置为 2）；已保存的项再按则删除 |
| `↑` / `↓` | 在候选列表内移动高亮（长按可快速连续移动） |
| 光标在末尾 + `→` | 进入后缀补全 |
| 光标在最前 + `←` | 进入前缀（颜色）补全 |
| 后缀模式 + `←` | 回到标准补全 |
| 前缀模式 + `→` | 回到标准补全 |

> 与原版的冲突处理：补全激活时通过 `InputMultiplexer` 在键盘设备之前插入处理器，消费 `↑/↓/Tab/←/→`，阻止原版「聊天历史翻页」与「Tab 焦点跳转」；其余按键原样放行。
> 历史翻页：补全框未弹出时，`↑/↓` 交给原版历史翻页（可连续翻到上一句/上上句），且此过程**不弹出补全框**；重新敲字后才恢复正常补全。

## 设置菜单

游戏内「设置 → 快速补全」页面提供：

- 实时统计：总发送消息数、消息库条目数、最爱消息 Top3、最爱后缀、最爱颜色（含次数）。
- 设置：部分匹配最少字数（滑块，2~6，默认 3）、部分匹配 Tab「仅粘贴不替换」开关。
- 按钮：导出词库（复制到剪贴板）、导入词库（从剪贴板）、打开词库文件夹。
- 快捷键简要说明。

## 默认约定（v1，可按需调整）

1. 候选列表**滚动显示**，每屏最多 8 条，高亮移到顶部/底部时自动滚动查看更多。
2. `↑/↓` 长按**快速连续移动**（约 0.4s 后开始连发）。
3. 前缀匹配**大小写敏感**。
4. 颜色标签插入**不加**闭合 `[]`（整条染色）；预览直接显示染色文字。
5. 后缀「末尾片段」为启发式抽取（空格分词 / CJK 末尾 n-gram / 结尾标点），已按对话确认的方案实现。
6. `Tab` 补全后回到标准模式（标准/后缀/前缀一致）；模式切换用 `←/→`。

## 注意事项

- 纯 Windows 客户端；未考虑服务端与安卓。
- 编译/打包已在本地验证通过；**运行时需在真实客户端实测**（本 Agent 无法启动游戏）。
- 词库文件为纯 ASCII 编码（文本 base64 存储），删除 `wordlib.dat` 即清空词库。
